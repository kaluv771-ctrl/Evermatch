EverMatch assessment with a separate response page\n\nFiles: index.html, style.css, script.js, response.html, response.js\n\nHow to use:\n1. Keep all five files in the same folder.\n2. Open index.html in a browser, or upload all five files to your static web host.\n3. Submit the assessment. Feedback will open on response.html.\n\nPrivacy note: This is a front-end demo. The result is stored in sessionStorage for the current browser tab and is not submitted to a server or database.\nUpdate the counselling WhatsApp number in script.js and response.js if needed.\n
